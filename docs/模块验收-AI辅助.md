# AI 辅助

## 已实现

- Python + httpx 实现 OpenAI 兼容协议适配，可配置兼容云服务或本地模型；没有新增模型 SDK。
- 个人模型配置优先，管理员可维护系统默认配置；密钥使用现有 cryptography 加密保存，不通过 API 回显。
- 模型连接检测、按用户和项目隔离的会话、需求生成用例草稿、草稿编辑/放弃/确认入库。
- 草稿经结构校验后保存，入库与草稿状态同事务提交；重复确认返回同一用例，版本冲突返回 409；不会自动执行生成内容。
- 现有 Vue/Ant Design 实现 AI 页面和全局入口，未配置模型时提供清晰提示。
- 所有日志保留异常堆栈，关闭 Loguru 局部变量诊断以防模型凭证进入错误日志。

## 验证

首批 `pytest tests/test_ai_assistance.py -q`：5 项通过。并发与网络边界补强后，**20 passed，5 warnings，4.14 秒**。HTTP 协议替身验证请求地址、Host、TLS SNI、Authorization、配置加密、无配置提示、异常 JSON、超时、用户/项目隔离。

2026-10-05 补强记录：

- 会话新增 `revision` 条件更新。两个窗口同时基于旧消息提交时，一个成功、一个收到 409；已保存的对话不会被后提交者覆盖。
- 草稿编辑、放弃、入库均以 `status=draft AND revision=请求版本` 原子领取，SQLite 与 MySQL 均有效；后续写入在同一事务完成。人工确认入库以 `AI-<草稿ID>` 作为唯一用例编号，重复或并发确认返回同一用例。
- 测试强制两个线程同时读到旧草稿版本，验证并发确认只产生一条用例、并发编辑只有一方成功、并发放弃与确认仅一方处理成功；注入入库中途失败验证领取版本、草稿状态、用例全部回滚。
- 模型请求前解析全部 DNS 地址，拒绝链路本地、多播、未指定地址及其 IPv4-mapped IPv6 表示，保留回环与 RFC1918 地址。本次连接固定到已经校验的 IP，并保留原 Host/TLS SNI，禁止重定向和隐式环境代理，避免第二次 DNS 解析更换目标。没有添加依赖。
- 网络边界检查使用模拟 DNS 与 HTTP MockTransport；没有连接真实供应商或读取真实模型凭证。

前端 `npm run type-check` 已通过；最终浏览器与整体回归记录在主验收文档。

## 用户确认的边界

本次暂不连接真实模型供应商。没有使用真实 API Key 或发送项目数据；供应商可用性、实际费用和生成质量不属于已验证项。

## 运维

可通过 `AI_ENCRYPTION_KEY` 环境变量设置独立加密根密钥；未设置时从持久 `JWT_SECRET_KEY` 派生。更换根密钥后需重新填写模型 API Key。模型基础地址填写含 `/v1` 的兼容入口；个人配置被停用后不会悄悄回退到系统配置。
