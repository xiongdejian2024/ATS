# 脚本作业前端

入口：左侧「脚本作业」→ `/script-jobs?projectId=<project>`。历史深链接同时包含 `jobId`、`runId`；切换项目时移除旧实体选择。

## 当前范围

- 独立项目作业列表、新建/编辑；Shell、Python、可执行文件均支持独立 argv 参数行。仅修改名称也会完整保留已有参数；冻结配置单独展示脚本/命令和精确参数。
- 节点仅来自当前用户有权使用的列表；离线节点仍可进入正式队列。在线不具备脚本能力时提示升级 Agent，控制端决定最终准入与派发。
- 相对工作目录、有限超时、脚本/参数大小验证；参数保留空格及空字符串，不在浏览器拼接 Shell 命令。
- 每次运行显示冻结配置与节点、队列/执行/终态、退出码、耗时、超时和错误。取消只提交已选择的 job/run ID。
- 派发未知时明确要求人工核对「从未启动或所有进程均停止」，勾选后才能「核对后关闭」。离开未知状态或切换运行会清除旧勾选。关闭记录不代表执行成功，也不会代替节点进程终止。
- 不依赖测试用例、测试套或结果 JSON；没有增加调度、Git 凭据或 DSL。

## 有界日志与请求生命周期

复用 `useBoundedLogs`、`BoundedLogViewer` 和 `RawLogDownload`。历史请求每次最多 20 条，每条服务器尾部最多 32768 字符；浏览器总视窗最多 512 KiB / 2000 行，连续重复行折叠并虚拟渲染。脚本日志使用独立 `/ws/script-jobs` 订阅，避免抢占现有测试套订阅。

每次服务器确认订阅或重连后重新读取权威历史，并按 offset 合并实时后缀。终态可能先于 Agent spool 补传，因此已选中的历史/终态运行也保持日志订阅；关闭详情、切换运行或离开页面才释放订阅。订阅确认前有 10 秒超时，确认后有 90 秒静默检测，1008 拒绝后停止自动重连。节点日志传输受阻时显示诊断，缺少诊断不代表日志完整。

原始日志导出路径包含冻结 job/run ID。完整保存逐段写入本地文件；不支持文件写入 API 的浏览器使用每次最多 256 KiB 的编号分段。只导出开始时服务器已接收的快照。切换运行、关闭或取消下载会中止请求与文件写入，旧响应不能显示成功。

运行提交期间禁止重复点击。网络失败后保留同一 `requestId`，用户重试只核对同一次提交；不会自动重跑。不确定编号按用户、项目、作业隔离，最多保留 64 个，存于当前标签页 `sessionStorage` 以跨刷新恢复；不会存储脚本或日志，且不会逐出未确认编号后产生新的运行。浏览器禁止该存储时显示刷新前核对提醒。所有读取与选择使用独立请求代次，旧结果不能覆盖新项目、运行或新打开的编辑框。
