# ATS 测试管理功能重实现

用户已确认：参考 MeterSphere V3 的功能与交互独立实现，保留 ATS 品牌；后端使用 Python，不复制 MeterSphere 源码，不引入 Java。模型服务暂不连接真实供应商，先完成可配置功能。原 Agent/XAT 与车型库继续使用，禁止真实台架执行。

| 模块 | 必须完成的业务链路 | 状态 |

| AI 辅助 | 个人/系统模型配置、密钥保护、连接检测、对话、结构化用例草稿；编辑确认后入库；无模型时明确提示 | 配置及协议链路已验收，真实模型按用户选择不连接 |

## 实现与验证原则

- 复用 FastAPI、SQLAlchemy、Celery、httpx、Vue 和 Ant Design Vue 等现有依赖。
- 新能力优先使用附加表；已有数据不清空、不重建，实际库变更前保留备份。
- 生成的 AI 用例先保存为草稿，用户确认后才进入用例库，不自动生成可执行台架命令。
- 任务派发、取消和结果必须走现有真实协议。测试使用隔离数据库及离线 XAT，不能用固定成功值替代执行结果。
- 异常记录完整堆栈；供应商密钥、登录令牌和项目数据不输出到提交或测试报告。
- 实际模型供应商调用不在本次验收范围，使用本地 HTTP 协议替身验证成功、错误和超时路径。
