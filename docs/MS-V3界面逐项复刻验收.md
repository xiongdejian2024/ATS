# MS V3 前端显示与功能项逐项复刻

## 完成判定

用户目标：测试用例、测试计划等功能的前端显示、功能项完整复刻 MeterSphere；每完成一部分提交远程仓库。保留用户已确认的 ATS 品牌与 Python 后端，不执行真实台架，不接真实模型。

**当前目标仍在进行。** 之前的141项软件测试和主要浏览器链路证明现有实现可用，不能证明UI与功能项100%一致。不得以已有绿色测试、功能大类相似或独立重实现为理由，缩小本目标。

基线固定于官方 `v3.6.9-lts`，Git对象 `d694f3aa7842f2fc19dd73ccb67e6b0b3a1b7b51`。依据官方Vue页面、配置、中文文案以及官方手册逐项对照。源码只作参考，新增代码独立实现。
