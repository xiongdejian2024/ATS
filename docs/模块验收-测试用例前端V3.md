# 测试用例前端 V3 工作台验收

## 实现范围

本模块沿用 ATS 品牌、Python 服务、现有 Vue / Ant Design Vue / ECharts 依赖。没有新增前端依赖，不连接真实 AI 供应商，不执行台架。

- 用例列表：高级组合筛选（AND / OR）、个人创建 / 关注范围、保存视图、服务器排序、名称行内编辑、跨页选择、批量属性 / 移动 / 复制 / 删除。
- 脑图：独立可复用 `CaseMindMap.vue` 使用 ECharts tree 布局和平移缩放。数据为模块 → 用例 → 前置条件 / 步骤 → 操作 / 预期；节点表单真实更新用例；添加 / 删除步骤；复制粘贴为新用例，剥离数据库身份和执行结果，保留模板字段。只读模式供计划执行与评审复用。
- 模板：默认模板、自定义文本 / 多行 / 数字 / 开关 / 日期 / 单选 / 多选字段、默认内容和字段值，必填前端提示与后端校验；项目自动重新提审开关。
- 详情：安全普通文本展示内容；附件真实 multipart 上传、鉴权 Blob 下载、删除；需求 / 缺陷创建、编辑和关联；前后置与相关用例；已有自动化用例 / ATS 执行模板 / 外部引用；关注、评论、分享链接、变更记录与关联计划 / 评审跳转。
- 回收站：分页 / 搜索、恢复、确认后彻底删除。不可删除的历史用例由后端返回冲突，前端不显示假成功。
- 导入导出：Excel / CSV / XMind 导入、同编号覆盖选项、明确的只校验模式；无模拟进度；Excel / XMind 真实下载；Excel 字段选择和用例行 / 步骤行布局。
- 独立评审 `/case-reviews`：单据列表 / 搜索 / 状态筛选、创建编辑复制关注、周期、逐条人员、用例列表 / 脑图、建议 / 改投 / 批量结论、自动下一条、快照提示、内容编辑、重新提审、历史与评论。单人按最后一次有效结论，多人按全部评审人最后有效结论；建议不算有效票；旧轮次 superseded 禁投。

## 实际接口约束

- 扩展 API 均携带 `/projects/{projectId}/case-features` 项目路径，评审 / 视图 / 批量走 `case-governance`。
- 复制用例调用实际 `case-governance/batch-copy`，不使用仓库原先未实现的 `/cases/{id}/copy` 路径。
- 上传显式设置 multipart，避免统一 API 客户端 JSON 默认头损坏 FormData。
- 只校验始终传 `validate_only=true`。导入失败保留校验错误，不发成功事件。
- 原详情 `v-html` 已删除；用户内容只以 Vue 文本插值显示。
- 捕获异常均用中文上下文加 `console.error(..., error)`，保留异常对象及堆栈。
- 关系记录不会自动执行或更改任务顺序；自动化关联不会触发执行。

## 浏览器验收清单

使用全新隔离项目，不接真实模型或台架：

1. 模板设置默认数字 / 必填 / 多选字段，新建用例验证默认值和必填；保存后打开详情检查值。
2. 上传文本附件，下载核对内容，刷新仍存在；删除后刷新消失。
3. 新建需求 / 缺陷、关联前置用例和自动化模板，添加评论并关注；刷新核对。
4. 脑图修改步骤和预期、增加步骤、复制粘贴；刷新核对新 ID 和内容。
5. 名称行内编辑、OR 筛选、名称排序、保存并恢复筛选视图。
6. 删除后回收站搜索并恢复；无历史用例可彻底删除，有历史应显示拒绝。
7. 导出 Excel 不同字段 / 布局及 XMind；文件仅校验导入时记录数不变；确认后按覆盖规则生效。
8. 单人 / 多人评审：建议不改变有效票、改投留历史、逐条人员、过期可投、自动下一条、重新提审保留旧单。
9. 切项目不复用旧选择，分享链接带项目和用例身份，桌面与窄屏操作可见。

本文不宣称浏览器清单已全部完成，主线程会记录实测证据。
